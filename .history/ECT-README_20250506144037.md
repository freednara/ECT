# Electoral College Tracking (ECT) Application

## Overview
The Electoral College Tracking (ECT) application is a Salesforce-based solution designed to manage and track the electoral college certificate process. It facilitates the coordination between state officials, NARA (National Archives and Records Administration), and other stakeholders involved in the electoral college certification process.

## Core Functionality

### Certificate Management
- **Certificate Pre-Review**: Tracks the initial review process of electoral college certificates
- **Certificate Review**: Manages the formal review process of certificates
- **Certificate Review Checklist**: Ensures compliance with requirements for both Certificate of Ascertainment and Certificate of Vote
- **Shipping & Tracking**: Monitors the physical delivery of certificates

### State Management
- Tracks state-specific information including:
  - State POC (Point of Contact) details
  - State seal information
  - Social media presence
  - Location and contact information

### User Management
- Role-based access control with specific permission sets for:
  - Congress Users
  - NARA Social Media Users
  - NARA Super Users
  - NARA Supervisory Users
  - OFR Legal Users
  - State Users

## Key Components

### Custom Objects
1. **ECT_State__c**
   - Manages state-specific information
   - Tracks state POCs and contact details
   - Stores state seal and social media information

2. **ECT_Certificate_Review__c**
   - Tracks certificate review process
   - Manages review status and comments
   - Handles social media posting and website updates

3. **ECT_Certificate_Pre_Review__c**
   - Manages initial certificate review
   - Tracks pre-review assignments and comments
   - Handles state POC communications

4. **ECT_Shipping_Tracking_Information__c**
   - Tracks certificate shipments
   - Manages delivery status and tracking numbers
   - Records shipping notes and timestamps

5. **ECT_Certificate_Review_Checklist__c**
   - Ensures compliance with certificate requirements
   - Tracks verification of state seals
   - Validates elector information and vote totals
